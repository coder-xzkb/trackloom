安装指南

整理方式

本地规则

用明确的歌曲标签或版本信息分类，例如粤语版或纯音乐。信息不足的曲目进入人工确认池。

可选 AI

默认服务商为 DeepSeek，也可切换 OpenAI 或填写兼容接口地址与模型。

复用目标歌单

为每一组指定已有歌单或创建新歌单。重复的歌曲会在写入时跳过。

安装扩展

  1. 从 GitHub 获取源码，运行 npm ci 和 npm run build。
  2. 在 chrome://extensions 打开开发者模式，选择「加载已解压的扩展程序」并加载 dist/。
  3. 登录网易云音乐网页，点击左下角的蓝色悬浮按钮打开插件。
查看完整安装说明

配置 AI 服务

在插件首页展开「AI 服务」，选择服务商，填写 API Key 后可测试并保存。API Key 留空时，仍可用本地规则整理歌单。
